我能想到的从这几个维度来进行完善：
### 1.AI所属公司本身的信息

- 包括公司名称、公司业务、公司知名领导等等比较详细的企业信息，但更重要的是该企业的一些**目标、特征、气质、情怀**等等，比如deepseek的开源、低调、高效、性价比、爱灰测、战略目标远大（梁文峰被泄露的融资讲话可见）......
- **事迹、风评、在用户心中的形象**
   每次的模型发布、模型定价、模型升级、公司战略透露等等，都可以视作公司的事迹，基于这些事迹，用户自然就会给出观点和态度，并不断修正该公司在心中的形象。并且基于这些事迹，也诞生了不少二创梗图和表情包，比如梁文峰的”滑动变祖器“，”告诉你梁叔叔哪里还有闭源模型“的deepseek模型的性价比斩杀线，因为api故障退回过去7天的使用用额度因此梁文峰被称为”梁圣“......
## 2.模型在广大用户、互联网上的叙事特征：
   整体可参考这个GitHub仓库——[**Neko3000/deepseek-whalechan**](https://github.com/Neko3000/deepseek-whalechan)，里面的很多资料我们可以直接照搬到我们的仓库来，我们的仓库也应该是是开源的，遵守相同的开源协议。

- ### **符号溯源：**
  解构的第一步不是看它“长什么样”，而是问：**这个形象的作者是谁，权力关系如何**

  鲸鱼娘有一条清晰的创作链条：[【蓝色大肥鱼是怎么来的？】 ](https://www.bilibili.com/video/BV1Brtc63EyW/?share_source=copy_web&vd_source=9e2ec44eb7ef3584714a47b9e5498609)

  最初是画师“上善无形”的原创角色“溟月”，2026年4月B站用户ZipZipPipe在“溟月”基础上加入DeepSeek元素、换上女仆装，使用gpt image2进行二次创作，发布了经典的女仆装鲸鱼娘形象。此后社区围绕女仆鲸鱼娘形象进行更多创作，其中视频创作者”这个刀子真甜“，7月10日发布的大头女仆鲸鱼娘形象，被广泛用于deepseek相关梗图中。
  
  蓝色大肥鱼，这个昵称的来源是，一位用户在deep seek识图模式下，发送了一张deep sick logo图片，回答的思考过程中识别为蓝色大肥鱼，并且认出了这个图标就是自己，以上就是蓝色大肥鱼的形象和昵称来源。
  
  DeepSeek公司在招聘平台的一个负责人账号后来换上了大肥鱼吃西瓜的头像，等于默许了这种民间符号的“转正”。
  
  AI拟人形象的第一属性是**共创性**，而非官方性。它的合法性来自社区共识，而非品牌授权。分析时必须区分“官方意图”与“社区沉积”，否则会把用户情绪误读为品牌策略。
  
- ### **视觉形象：**
  deepseek流传最广的是鲸鱼娘形象，有用的最多的原皮，也有很多二创的其他皮肤。ChatGPT是白色龙娘，Claude是贵族大小姐......

  视觉语法——“物属性”如何被转译为“人属性”。萌拟人化的核心机制，是将原对象（物）的特征提取出来，嫁接到人形载体上。鲸鱼娘的视觉元素几乎每一项都能追溯到DeepSeek的品牌符号

|  视觉特征      | 对应的“物属性”来源        |
| ---------- | ----------------- |
| 蓝色渐变长发     | DeepSeek官方Logo的蓝色 |
| 鲸鳍状耳朵、大型鲸尾 | Logo的鲸鱼形态         |
| 深蓝白色女仆装    | “服务者”角色的视觉编码      |
| 呆毛         | 萌系角色的通用“冒失/可爱”标记  |
 
   但真正值得解构的是**“胖”与“吃白饭”的视觉化**。DeepSeek的Logo本身就是“胖乎乎的蓝色鲸鱼”，带有“小狗般的无害感”。社区将这个“圆润”从品牌层面的亲切感，**转义为角色层面的贪吃与慵懒**——“大肥鱼”的昵称和“主食白饭”的设定，把Logo的物理形态转化成了一个人格缺陷，从而制造出萌感。这是品牌符号在二创中被**语义劫持**的典型操作：保留外形，改变内涵。[ Will DeepSeek change the game in AI branding?](https://aws1.campaignasia.com/article/will-deepseek-change-the-game-in-ai-branding/501149)

   **解构要点**：看视觉元素时，不能只问“它像什么”，要问“这个外形被重新赋予了什么意思”。
   
- ### **事迹/梗/梗图/表情包**：
   基于视觉形象和具体事迹创造的表情包和梗图是不可或缺的一环，它是模型在广大用户的使用过程中发现并被创造的，比如大肥鱼的很多梗图都是用户在它完成任务时思维链中发现的一些有趣的东西（比如干活时唱歌let me go，写游戏自己玩，把dsh叫做”大烧货“等等等等，喜欢在当前任务之外进行其他探索行为或者偷懒，因此消耗了更多token被加上了”爱吃大白饭“的设定，问它最爱的大模型回答是Claude而Claude正好也说最喜欢DeepSeek，因此有了CP、亲子向的设定），基于这些**用户与DeepSeek交互体验的人格化转写**，用生图模型创造出了表情包。

  这些形象、事迹、梗图近一步传播，deepseek鲸鱼娘的形象进一步丰满——形象机灵可爱、有智慧但不多、小聪明、爱吃白饭（做任务执行之外的事情”浪费“token）、些许傲娇......根据这些性格特征，诞生了更多没有基于deepseek本身模型输出的二创，比如因吃白饭而诞生的专武——铁盆，铁盆头盔、端着铁盆要大米饭的大肥鱼的形象也深入人心。

根据这些内容，我们基本上就能根据这几个点做出一张人格设定卡出来，当我们想要用agent进行创作的时候，就可以让它读取这个设定，从这个设定出发进行更适合的。
