## 二、真正的使用过程

### 过程 A：用户想给“吃白饭”写一首打油诗

打开角色入口 → 进入“白饭与 Token”梗卡 → 看到 1–3 张代表素材 → 理解具体情境和笑点 → 进入诗歌素材盘看词语、反差、可选收尾。原帖证据放后面，创作不必每次先读一页考据。

### 过程 B：Agent 要做一张“被催工作”的表情包

读取入口卡 → 读取情境反应中“被催”一项 → 从图册找动作／表情 → 读取相应 Q 版视觉参考 → 得到一份明确的小型参考包。此次只是完善这个读取路径，不执行生图。

### 过程 C：用户又收了几张新图

放入“表情包/待整理” → 看图确认内容 → 分配未用的新编号 → 记录展示名与标签 → 移入单一分类 → 加入既有索引／图册；有事件则关联，无事件可作为普通反应图。无需为了一个新表情创建整篇事件报告。
