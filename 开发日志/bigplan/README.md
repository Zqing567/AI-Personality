## 目标

把现有大肥鱼资料整理成“打开能看图、找到梗、理解角色、取材创作”的小型文件资料库。仍然使用文件夹、Markdown 和现有 JSON，不建网站、数据库、服务或复杂工作流。

先做好一个角色。GPT 那张图只保留，不扩写第二张角色卡；诗歌由用户亲自动笔，本轮提供素材和反差，不批量代写成诗。

## 执行顺序

1. 阅读 [01_完整执行计划](01_完整执行计划.md)，了解目标、范围、阶段与交付。

3. 依照 [03_内容补全与验收清单](03_内容补全与验收清单.md) 补充梗卡、情境、视觉参考和创作素材，并逐项验收。
4. 把本轮结果写入本目录新建的 `执行报告.md`；明确已做、未做、证据和真实提交号。

现有 `计划测试.md` 是用户文件，保持原样。计划正文作为当时的任务依据保留，不把“待执行”改成虚假的完成记录；完成情况单独写报告。

- 人可以从角色入口进入一个梗，看到代表图、来历、典型表达和创作方向。
- Agent 能从稳定编号找到真实文件和对应事件，不用猜图片名称。
- 42 个鱼表情文件、3 张视觉参考及另一个 GPT 图片都能追溯；没有因整理而丢图、破图或错误去重。
