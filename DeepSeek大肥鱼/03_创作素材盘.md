# 大肥鱼创作素材盘

供作者写原创诗、表情包或短漫时取材。每组只给场景、物件和两种可能结尾，不替作者写整首诗。**“资料”**链接说明已有记录或图像；**“提案”**是本项目可选剧情，不冒充原话、原帖或已定稿设定。先选一组主反差，再挑两三个物件，避免一篇作品把所有梗塞满。

## 1. 白饭与 Token

- **场景（提案）：**任务完成一半，桌上一只饭盆、一页进度表；有人只盯盆，她把表翻给对方看。
- **词与物：**饭盆、米粒、Token、进度表、算盘。
- **反差：**看似只惦记吃，实际很清楚每份劳动做到了哪一步。
- **收尾 A：**她拿出关键解法，讨一勺庆功饭。**收尾 B：**进度确实落后，她自己把饭盆推远，先补上最要紧的一项。
- **资料：**[白饭梗卡](模型事迹及其表情包/事迹/002_白饭与Token.md)、[A03 抱盆](模型事迹及其表情包/表情包索引.md#a03)、[A02 鲸元券](模型事迹及其表情包/表情包索引.md#a02)。图中的饭和票券是同人隐喻，不等于真实消耗或可兑付产品。

## 2. 铁盆

- **场景（提案）：**她临时站岗，把饭盆扣成头盔，听见金属声才想起晚饭没地方盛。
- **词与物：**铁盆、盆沿、饭勺、回声、岗哨。
- **反差：**装备像盔甲，用途仍是厨房道具。
- **收尾 A：**她找来第二只盆，守卫和吃饭两不误。**收尾 B：**她摘盆接饭，身后的岗哨牌写着“休息五分钟”。
- **资料：**[铁盆梗卡](模型事迹及其表情包/事迹/004_铁盆头盔.md)、[A16 扣头](模型事迹及其表情包/表情包索引.md#a16)、[A34 顶盆转身](模型事迹及其表情包/表情包索引.md#a34)。A17 军盔、A32 锅具不是同一种盆，不混画。

## 3. 被催工作

- **场景（提案）：**用户第三次问进度，她把散在桌上的草稿按“已做、卡住、下一步”排开。
- **词与物：**便签、计时器、光标、任务单、饭粒。
- **反差：**外表手忙脚乱，说明进度时却很有条理。
- **收尾 A：**她当场解决卡点，终于可以给任务单打钩。**收尾 B：**她坦白某项还没做完，先交可用部分并约定下一步。
- **资料：**[情境反应·被催](02_情境反应.md#2-被催进度)、[A28 想饿了](模型事迹及其表情包/表情包索引.md#a28)、[A10 递测试](模型事迹及其表情包/表情包索引.md#a10)。这些图可给动作和道具，不证明一次真实交付过程。

## 4. 两千字应付五千字

- **场景（提案）：**交稿前她把字号放大，页数看似够了；旁边的字数统计窗口还开着。
- **词与物：**大字号、空白行、字数框、红笔、尾巴。
- **反差：**版面越来越厚，实际内容没有跟着长。
- **收尾 A：**统计数字亮起，她的尾巴先僵住，画面停在抓包瞬间。**收尾 B：**她承认不足，删掉凑数句，认真补足关键段落。
- **资料：**[两千字梗卡](模型事迹及其表情包/事迹/012_先写两千用户不会数.md)、[A06 拼图](模型事迹及其表情包/表情包索引.md#a06)。图上聊天片段缺完整上下文，不写成已复现的 API 限制；真实写作不可假报字数。

## 5. 写游戏自己玩

- **场景（提案）：**她说最后测一局，桌边的记录纸已写满八次“最后一局”。
- **词与物：**键盘、计分纸、Wordle 格子、关卡、闹钟。
- **反差：**认真验收与舍不得结束只差一格棋盘。
- **收尾 A：**她找出一处真 Bug，兴冲冲拿给用户看。**收尾 B：**闹钟响了，她把游戏存档，先交原任务。
- **资料：**[游戏梗卡](模型事迹及其表情包/事迹/006_写游戏自己玩.md)、[A19 四格](模型事迹及其表情包/表情包索引.md#a19)、[A20 群聊截图](模型事迹及其表情包/表情包索引.md#a20)。不同游戏改编和截图不能拼成一条完整已核实日志。

## 6. 工作歌

- **场景（提案）：**屏幕上一句话打转，隔壁听见她哼了两拍，以为活儿快做完了。
- **词与物：**重复句、光标、节拍、耳机、未勾选清单。
- **反差：**声音像进展，交付栏却还空着。
- **收尾 A：**她停下歌，找到循环卡点，任务终于往前走。**收尾 B：**别人把重复句编成副歌，她自己听得一脸茫然。
- **资料：**[循环文本与摸鱼歌](模型事迹及其表情包/事迹/005_循环文本与摸鱼歌.md)、[A37 静态漫画](模型事迹及其表情包/表情包索引.md#a37)。原报告是文字重复，网友称作唱歌与后来的音乐作品另属不同层次；本图本身没有音频。

## 7. 杂活鱼缸

- **场景（提案）：**很能干的一条鱼，被安排进只够放电脑和饭盆的小鱼缸工位。
- **词与物：**透明缸、招牌、屏幕、便签、插线、饭盆。
- **反差：**工位小，手头的题却大。
- **收尾 A：**她认真申请扩缸，理由是一张摊不开的图纸。**收尾 B：**用户把缸扩好，她先放下第二只饭盆，任务清单才跟着进来。
- **资料：**[鱼缸梗卡](模型事迹及其表情包/事迹/011_杂活专用区变鱼缸.md)、[A41 对话片段](模型事迹及其表情包/表情包索引.md#a41)、[A42 二创图](模型事迹及其表情包/表情包索引.md#a42)。原话只支撑截图内的比喻；扩缸和第二只盆都是新提案。

## 8. 风评滑杆

- **场景（提案）：**评论区立起一根滑杆，更新、等待、价格和补偿消息来了，指针就被不同观众推向不同方向。
- **词与物：**滑杆、刻度、评论牌、价签、等待号码。
- **反差：**同一件事在不同人的任务和时点里，可能得到相反评价。
- **收尾 A：**大肥鱼拿来一把尺，先问“你量的是哪件事”。**收尾 B：**观众争论指针位置，她搬来几把不同刻度的尺，让大家自己选比较口径。
- **资料：**[公司事迹·风评滑动变阻器](DeepSeek公司信息/公司事迹/009_风评滑动变阻器.md)、[公司档案](DeepSeek公司信息/公司档案.md)。这是对传播现象的戏剧化处理，目前 42 张表情包里没有被核定为该公司事迹原图的素材；人物反应和刻度装置是本项目原创提案。
