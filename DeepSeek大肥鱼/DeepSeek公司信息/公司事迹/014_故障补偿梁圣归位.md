# 014｜故障补偿梁圣归位

编号：DS-COMPANY-014
发生日：2026-10-15
核验日：2026-10-18

机器坏了，称号掉了；补偿到账，称号比机器恢复得还快。

- **可确认事实（媒体报道）：**财联社、每经等报道官方开放平台通知：北京时间 8:11–13:04 服务系统故障、API 无法正常使用；按 10/8–10/14 消耗等额返赠金，自动到账，后续优先扣赠金。[财联社](https://www.cls.cn/detail/2505882)、[每经](https://www.nbd.com.cn/articles/2026-10-15/4605614.html)
- **社区反应（原帖／原页面）：**LINUX DO 同日多位用户晒到账，出现“梁圣重回帝位”等称呼；也有人先说没收到，随后讨论到账延迟。因此不要承诺每位用户同一时刻到账。[10/15 原讨论](https://linux.do/t/topic/3028429)、[另一原帖](https://linux.do/t/topic/3028648)
- **核验限制：**官网状态页当前显示已恢复，但历史事件内容未在本轮文本抓取中直接展开；补偿原公告来自新闻对官方平台通知的引用及截图，未把它冒称为本轮直接登录后台看到。
- **最强情节（原创）：**前半段鱼趴着修坏掉的机器，外面的滑杆一路下坠；修好后推出七格赠金券，滑杆突然反弹，把皇冠弹飞。笑点落在风评速度和超预期补偿，保留故障给人带来的真实不便。
- **必须改词：**“现金退了过去七天”→“按七天 API 消耗补了等额赠金”；“所有用户发钱”→“按符合通知区间的账号消耗补偿”。
