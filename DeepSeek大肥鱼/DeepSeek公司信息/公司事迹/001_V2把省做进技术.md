# 001｜V2把省做进技术

编号：DS-COMPANY-001
发生日：2024-05-06
核验日：2026-10-18

它第一次把计算器摆上桌，其他人的价签就显得有点不自在。

- **可确认事实（官方）：**官方发布 V2，论文／仓库列出 236B 总参数、每 token 激活 21B；相对自家 DeepSeek 67B 报告训练成本下降、缓存占用减少和吞吐提升。比较基线要写清楚，不能套成“比所有对手省同样百分比”。[V2 官方仓库](https://github.com/deepseek-ai/DeepSeek-V2)、[论文](https://arxiv.org/abs/2405.04434)
- **人物可用冲突（创作推断）：**同样一桌菜，它研究的是怎样少开几个灶，省下来的费用反映到报价。
- **戏剧转译（原创建议）：**别人长篇介绍豪华套餐，大肥鱼安静贴出一张极短价签，隔壁全体重新拿计算器。
- **边界：**不要说“低价只能靠补贴”；也不要反过来声称所有价格差都由某一个技术直接解释。
