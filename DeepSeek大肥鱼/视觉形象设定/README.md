## 六件事分别选

| 要选的内容 | 例子 |
|---|---|
| 身份 | 这是谁，哪些特征让人认得出来 |
| 画风 | 线稿、赛璐璐、水彩、三维等 |
| 服装 | 女仆装、雨衣、日常服，按作品决定 |
| 比例 | Q版、较修长等；比例变化不等于年龄变化 |
| 动作 | 抱盆、端饭、打字、叉腰，注意手和道具接触 |
| 场景 | 桌前、厨房、水边、透明背景等 |

例如，用女仆三视图当身份参考、另选雨衣造型时，不必把白围裙和所有裙边塞进雨衣；但也不能把头发、脸与鲸尾一起换成另一个角色。一个作品里的各张图尽量保持同一设计，换皮另记版本。

本轮仅查看与索引用户原图，没有生成新的立绘、三视图、表情或三维模型。缺的视角若以后创作补齐，应标“补设”，不能称找回原作者设计。

## 哪些固定，哪些不必固定

- **参考图可见：**A44、A45、A46 都有蓝系长发、蓝眼、呆毛、鲸系侧饰与尾巴；A44 是大头短肢的 Q 版，A45/A46 是较修长比例。A44 侧面还可见人耳，角色并非只有鱼尾而没有腿脚。
- **创作建议：**一次作品先选 A44 或 A45/A46 为主参考，再统一脸、发、侧饰与尾巴；不要把 Q 版裙边、长身露肩袖和鞋型拼成一套“原设”。
- **可变化项：**服装、画风、动作、背景和头身比例随作品选择。女仆装是这组图的服装，不是任何场景都必穿；铁盆、饭碗、枪械、锅铲是具体作品的道具，不常驻身体。
- **仍未知：**精确色值、头身比、背面未展示的结构与正式作者授权没有统一测量或逐项核清，不伪造数字约束。

## 画错时先核对

1. **认不出来：**先比头顶到发梢的蓝色层次、弯呆毛、侧鳍、眼睛和鲸尾，再改衣服或表情；不要只靠蓝色头发代替全部识别点。
2. **比例混了：**A44 的短肢和短裙与 A45 的长裙、露肩、分离感袖口及较高跟鞋分别成套；不是把同一张图等比例拉长或压扁。
3. **尾巴或道具混了：**鲸尾是识别部位，铁盆可摘；A17 的军盔和 A32 的烹饪锅具不能自动画成铁盆皮肤。
4. **三视图缺细节：**A46 只给单幅正面立绘；侧面、背面查 A45。若所选服装缺视角，标“本次补设”，不称原作者已有设计。
