## 本轮能用到什么

入口卡保留“聪明能干、可爱、有点小得意、会被支线吸引”的矛盾。白饭和铁盆可以是道具，能衍生护食、记账、分享、庆功、走神等不同场面，不把人物写死成只会偷懒。

公司素材覆盖研究取向、开权重与工具、价格变化、灰测讨论、性价比斩杀线、风评滑杆，以及 10 月 15 日故障后的七天 API 消耗赠金补偿。人物如何反应是创作选择，不是对公司或创始人心理的事实判断。

社区材料补到了“循环文字被拟人化成工作歌”的用户原报告，也区分了 5 月已有的小 AI／Q 版路线与 7 月的重要传播分支。相关页面的题目、简介或截图可核，不等于已完整观看所有视频，也不等于所有故事已拿到原始日志。
